# Daydream VR Range — мобильный VR-тир на Godot 4 + контроллер Daydream (BLE)

Игра для телефона на Android: стерео-режим для очков типа Cardboard (две половины экрана,
линзовая коррекция, слежение за головой по гироскопу), а лучом-указкой управляет
контроллер Google Daydream по Bluetooth Low Energy. Сбивайте шары за 60 секунд.

Проверено: логика разбора пакета Daydream (раскладка битов) прогнана круговым тестом.
**Не проверено на устройстве**: Godot и Android SDK в моей среде нет, AAR я собрать не мог
(у сборки нет доступа в сеть). Поэтому ниже есть раздел «Что подстроить на телефоне».

## Быстрый путь: готовый APK через GitHub (без установки Godot и Android SDK)

1. Создайте на github.com новый репозиторий и загрузите в него содержимое этой папки
   (кнопка *Add file → Upload files*; папка `.github` должна попасть внутрь).
2. Откройте вкладку **Actions → Build APK → Run workflow** (сборка запускается и сама при каждой загрузке).
   Сборка занимает около 10–15 минут.
3. Готовый файл лежит в **Releases → «Последняя сборка»**. Постоянная прямая ссылка:
   `https://github.com/<ваш-логин>/<репозиторий>/releases/latest/download/DaydreamVR.apk`
   (для приватного репозитория скачивайте со страницы Releases или из Actions → Artifacts).
4. Откройте ссылку на телефоне, скачайте APK и разрешите установку из неизвестных источников.

APK подписан отладочным ключом — для личного использования этого достаточно.
Сборка настроена по инструкции для Godot 4.3, но я её не запускал: если Actions покажет ошибку,
пришлите текст лога — поправлю.

## Состав

| Путь | Что это |
|---|---|
| `project.godot`, `main.tscn` | проект Godot 4.3+ (GL Compatibility, ландшафт, датчики включены) |
| `scripts/main.gd` | игра: мишени, луч, очки, HUD |
| `scripts/vr_rig.gd` | стерео-камеры, сплит экрана, линзовая коррекция |
| `scripts/head_tracker.gd` | голова: гироскоп + акселерометр (на ПК — мышь, правая кнопка) |
| `scripts/daydream_controller.gd` | автозагрузка `Daydream`: приём пакетов, калибровка, кнопки |
| `scripts/daydream_parser.gd` | разбор 20-байтового пакета Daydream |
| `android_plugin/` | Kotlin-плагин `DaydreamBle`: сканирование, GATT, уведомления |
| `addons/daydream_ble/` | редакторный плагин, подключает AAR при экспорте |

## Как это работает

1. Плагин `DaydreamBle` ищет BLE-устройство с именем «Daydream» (или сервисом `0xFE55`),
   подключается и включает уведомления характеристики `00000001-1000-1000-8000-00805f9b34fb`.
2. Каждый пакет (20 байт) уходит в Godot как hex-строка, `DaydreamParser` достаёт из него
   ориентацию (вектор «ось × угол»), гироскоп, акселерометр, тачпад и кнопки.
3. `Daydream.orientation` — это ориентация контроллера после калибровки; игра рисует
   контроллер и лазерный луч и стреляет по нему.

## Сборка

1. **Плагин.** Нужны JDK 17, Android SDK и gradle 8.x (или Android Studio):
   ```bash
   export ANDROID_HOME=~/Android/Sdk
   ./android_plugin/build_plugin.sh
   ```
   В `android_plugin/build.gradle.kts` версия `org.godotengine:godot` должна совпадать с вашим Godot.
   Результат: `addons/daydream_ble/bin/daydream_ble.aar`.
2. **Godot 4.3+:** откройте проект, в *Project → Project Settings → Plugins* включите **Daydream BLE**.
3. *Project → Install Android Build Template…*
4. *Project → Export → Android*: включите **Use Gradle Build**, укажите keystore (для отладки хватит debug),
   минимум Android 7.0 (API 24).
5. Запустите на телефоне. Разрешения Bluetooth запросятся автоматически.

## Управление

| Действие | Что происходит |
|---|---|
| Клик по тачпаду | выстрел (на экране итогов — новый раунд) |
| Home, удерживать ~0.6 с | центровка: смотрите прямо, направьте контроллер прямо |
| App | перезапуск раунда |
| Тачпад (касание) | синяя точка на модели контроллера (проверка связи) |
| Без контроллера | целитесь головой, тап по экрану — выстрел |
| ПК | правая кнопка мыши — поворот головы, ЛКМ/Пробел — выстрел, `R` — центровка, `V` — моно/стерео |

## Подключение контроллера

Заряженный контроллер: нажмите Home (при первом подключении удерживайте Home, пока не замигает
индикатор). Плагин сам сканирует эфир и переподключается каждые ~6 секунд. Статус виден внизу HUD
(там же счётчик принятых пакетов — если он растёт, данные идут).

## Что подстроить на телефоне

* **Знаки гироскопа.** Если при повороте головы картинка едет в обратную сторону, поправьте
  `GYRO_SIGN` в `scripts/head_tracker.gd` (например, `Vector3(1, -1, 1)`).
* **Рысканье дрейфует** (магнитометр не используется): центруйте Home / клавишей R.
* **Оси контроллера.** Если луч смещён на 90° или инвертирован после центровки, поправьте
  `pointer_direction()` в `scripts/daydream_controller.gd` (сейчас луч = `orientation * (0,0,-1)`)
  или добавьте постоянный поворот к `_raw`.
* **Нет пакетов, но статус «уведомления включены».** Некоторые прошивки контроллера нужно «разбудить»
  повторным нажатием Home; если не помогает — отпишите, добавлю запись команды запуска в характеристику.
* **Размер/FOV/IPD/линзы:** экспортируемые параметры `VRRig` (`ipd`, `fov`, `render_scale`,
  `lens_k1`, `lens_k2`) и `shaders/lens.gdshader`.
* Для Android 12+ плагин объявляет `BLUETOOTH_SCAN` с флагом `neverForLocation`.
